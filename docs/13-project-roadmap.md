# 13 — Project Plan and Roadmap

## Phase 0 — Foundation

Deliver repository structure, workspace scripts, environment example, Supabase local setup, documentation, and synthetic-only banner.

**Exit gate:** clean install and local application launch.

## Phase 1 — Data and access control

Deliver schema migrations, role/unit assignments, private raw tables, RLS on release/report tables, seed generator, and negative permission tests.

**Exit gate:** no commander or anonymous path to raw personnel data.

## Phase 2 — Analytics and privacy release

Deliver quality checks, weekly metrics, transparent score, comparable baseline, stable noisy count release, and suppression.

**Exit gate:** fixture values and under-five behavior pass automated tests.

## Phase 3 — Commander experience

Deliver unit card grid, trend charts, accessible explanations, and suppressed/insufficient states.

**Exit gate:** commander walkthrough works without showing individuals.

## Phase 4 — Reports and AI

Deliver idempotent weekly alert generation, welfare inbox, validated aggregate briefing, switchable provider, deterministic fallback, and print-to-PDF page.

**Exit gate:** one elevated synthetic unit yields one assigned report even after cron retry.

## Phase 5 — Audited exception

Deliver reasoned 30-minute grants, transactional per-read audit, limited individual records, and officer audit viewer.

**Exit gate:** wrong role, unit, reason, and expiry are all blocked.

## Phase 6 — Hardening and presentation

Complete accessibility and API tests, optimize measured bottlenecks, confirm synthetic-only deployment, record actual screenshots, and export the six-slide SIH template to PDF.

**Exit gate:** all release-blocking tests in `11-testing-plan.md` pass.

## Later work, not MVP claims

Optional consented mobile wellness check-in, HRMS adapter, professional validation of thresholds, approved notifications, multilingual content, and sponsor-approved deployment.

## Scope-control rule

If time runs short, preserve in this order: **access boundaries → reliable aggregate scoring → report workflow → fallback explanations → optional AI polish**. Do not remove privacy checks to improve the demo.
